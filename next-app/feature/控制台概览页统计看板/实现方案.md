### 2.2 总体架构与数据流（摘录）
- 页面入口：`app/(app)/page.tsx` 仅渲染 `DashboardOverviewPage`，不承载复杂逻辑。
- Dashboard 页面（Client）：
  - 读取 URL query（`timeWindow/channel`）作为 filters 单一事实来源。
  - 调用 `useDashboardOverview(filters)` 获取数据，控制 loading/empty/error/auth/disconnected。
  - 组织布局：KPI、趋势、Top Models、Action Center、稳定性、配置健康。
- 聚合 API（Server Route Handler）：`app/api/dashboard/overview/route.ts`
  - `requireSession()` 鉴权。
  - parse & validate query（timeWindow/channel）。
  - 并行拉取：usage 聚合、topModels、pipeline、system health、configHealth、logsMeta。
  - `Promise.allSettled` + per-source timeout 实现“局部降级不阻塞首页”。

### 2.3 关键时序/算法（摘录）
- Filter 变更竞态治理（Client，伪代码摘录）：

```ts
let requestSeq = 0;
let currentAbort: AbortController | null = null;

async function runFetch(filters) {
  requestSeq += 1;
  const seq = requestSeq;

  currentAbort?.abort();
  const ac = new AbortController();
  currentAbort = ac;

  setState({ kind: "loading", filters });

  try {
    const res = await fetch(buildUrl(filters), { signal: ac.signal });
    if (seq !== requestSeq) return;
    // handle 401 / error / ok
  } catch (e) {
    if (e?.name === "AbortError") return;
    if (seq !== requestSeq) return;
    setState({ kind: "error", ... });
  }
}
```

- 聚合 API 并行与局部降级（Server，伪代码摘录；注意 timeout 可取消需按“审阅标注”升级）：
