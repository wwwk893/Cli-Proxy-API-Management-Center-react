# 任务计划

- 时间戳：2025-12-21 16:08

## 背景/需求/目标/范围
### 背景
聚合管线当前的新建聚合任务仅支持按日期创建，缺少对模型型号与渠道的组合筛选，也未提示筛选条件下可用数据的最早时间点。

### 需求
在新建聚合任务弹窗内支持模型与渠道多选/全选的自由组合筛选，并展示基于筛选条件的最早数据时间点，同时整体 UI 视觉与交互升级；日期范围仍仅允许过去日期。

### 目标
- 提升筛选能力与可用性，让用户明确最早可聚合时间点。
- 让弹窗交互更清晰、信息层级更友好、整体视觉更高级。

### 范围（做什么）
- 新建聚合任务弹窗 UI 重构与筛选逻辑扩展。
- 新增/调整后端接口支持筛选条件与最早数据点查询。
- 创建任务参数携带筛选条件并可被后端消费。

### 范围外（不做什么）
- 不改历史任务展示逻辑。
- 不改成本回填逻辑。
- 不引入自动化流水线或后台任务编排改造。

## 验收标准
- 支持模型多选/全选、渠道多选/全选，并可自由组合。
- 单任务携带筛选条件（不拆分多任务）。
- 显示基于原始 usage 事件、本地时区计算的“最早有数据时间点”。
- 日期范围仅允许过去日期；默认开始日期为最早数据点、结束日期为昨天。
- 弹窗整体视觉明显升级且交互清晰。

## 风险与回滚（🧯）
- 风险：新增筛选字段影响聚合任务重复/唯一性判断与历史任务兼容。
- 回滚：保留旧接口参数处理逻辑；如异常，可暂时关闭筛选 UI 并回退到仅日期创建。
