背景/需求/目标/范围（含不做什么）
- 背景：使用概览的“模型排行”仅展示总 Token/成本，无法快速理解输入/输出/思考 Token 与对应价格构成。
- 需求：为每个模型行提供明细查看（hover + 点击），展示输入/输出/思考 Token 与输入/输出金额；价格按现有计费规则计算，且使用当前 ModelPricing。
- 目标：不改变现有统计口径与排序逻辑，在模型行可快速查看明细与价格构成，并在未配置价格时明确提示“未配置”。
- 范围内：模型排行表格行内明细展示、后端接口返回明细数据、前端展示与交互、i18n 文案补充。
- 不做：新增统计维度/重算历史数据/更改计费规则/改动非模型排行页面/历史价格回溯。

验收标准
- 模型行支持 hover 与点击方式查看明细，触控设备可点击查看。
- 明细字段齐全：输入 Token、输出 Token、思考 Token、输入金额、输出金额；未配置价格显示“未配置”。
- 明细数值与当前筛选条件/时间范围一致，不影响原有排序与筛选。
- 行展开（来源行）不要求展示明细。

风险与回滚（🧯）
- 风险：接口变更可能影响现有前端渲染；价格拆分规则理解偏差；明细展示与行点击/展开冲突。
- 回滚：回退接口新增字段与前端明细展示组件；保留原表格展示逻辑不变。
