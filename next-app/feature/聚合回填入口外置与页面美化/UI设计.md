### 草图（页面布局）

```
┌────────────────────────────────────────────────────────────────────────┐

│ 管理用量聚合任务与回填。                                              │
├────────────────────────────────────────────────────────────────────────┤

├────────────────────────────────────────────────────────────────────────┤

├────────────────────────────────────────────────────────────────────────┤

│ 任务列表表格                                                         │
│ ┌───────────────────────────────────────────────────────────────────┐ │

回填成本（独立抽屉/弹窗，非“新建聚合”弹窗内）
┌──────────────────────────────┐
│ 回填成本                      │
│ 说明：仅补齐 costUsd=0/NULL...│
│ 起始日期 [____] 结束日期 [__] │
│ [取消]            [回填成本]  │
└──────────────────────────────┘
```

### 交互逻辑说明
- 首次进入：骨架屏显示统计卡片与表格；回填提示条保持占位，避免布局跳动。
- 正常态：提示条 + 右侧双按钮（回填成本为次按钮，新建聚合为主按钮）。
- 回填入口：点击“回填成本”打开独立抽屉/弹窗（与新建聚合弹窗完全独立）。
- 提交回填：按钮 loading，成功后关闭弹窗并在页面顶部提示“已回填成本事件数：X”，失败则保留弹窗并显示错误。
- 空态/错误：空态仍显示回填入口；错误态保留提示条但按钮禁用并提示原因。

### 关键视觉细节
- 提示条：使用淡色背景（bg-muted/50 或浅琥珀色），轻量提示 + 明确 CTA。
- 按钮层级：回填成本 `outline`，新建聚合 `default`，避免主次冲突。
- 间距：提示条与筛选区保持 12–16px 间距；表格上方使用轻分割线。
- 可访问性：提示条 `role="status"`，按钮具备 `aria-label`，抽屉打开时自动聚焦日期输入。

### 交互逻辑说明（当日限定）
- 页面外置入口改为“回填当天”，无需日期选择，1 次点击即可触发。

- 成功后提示“已回填成本事件数：X”，并保持“新建聚合”作为历史回填入口。

### 视觉要点（今日限定）
- 提示条文案前置，强调“仅今天”，避免误解范围。
- “回填今天”按钮为 `outline`/次按钮，“新建聚合”为主按钮。
- 弹窗文案用 `Alert` 轻量容器，保持简洁。

## 附：验收点清单
- 视觉层级：回填成本为次按钮，新建聚合为主按钮，提示条不抢主视觉。
- 交互完整：回填成功/失败提示明确；弹窗关闭逻辑无卸载告警。
- 状态覆盖：加载、空态、错误态下入口显示逻辑清晰。
- 可访问性：焦点管理正确、键盘可操作、提示条对比度达标。
- 性能：回填触发仅刷新必要数据，不引入额外大范围渲染。
