### 1. 信息架构 (Information Architecture)
*   **`/` (Dashboard)**: 全局概览。聚合连接状态、核心指标 (Cache/Cost)、快捷入口。
*   **`/login`**: **连接管理**。输入 API Base/Key -> 验证连接 -> 存储 LocalStorage。
*   **`/settings`**: **基础设置**。包含：通用开关 (Debug/Retry)、代理设置 (Proxy URL)、通用 API Key 管理。
*   **`/settings/providers`**: **模型渠道**。Tab 分组：Google / OpenAI / Anthropic / Custom。列表展示 + 添加/编辑模态框。
*   **`/auth-files`**: **凭证文件**。文件列表 (Grid/List 切换) + 拖拽上传区域 + 搜索/筛选栏。
*   **`/config`**: **配置编辑器**。全屏 Monaco Editor + 顶部工具栏 (重载/保存/下载)。
*   **`/system`**: **诊断与信息**。版本信息、环境检测、健康度检查列表。
*   **保留路由**: `/usage`, `/logs`, `/pipeline`, `/pricing` (维持现有设计，仅对齐 Header/Nav)。

### 2. 关键交互流程 (Key Interaction Flows)
*   **Config Editor (配置编辑)**:
    *   *Init*: 加载 YAML -> Loading Skeleton -> 显示编辑器。
    *   *Edit*: 修改内容 -> 检测 Diff -> 启用 \"Save\" 按钮 (高亮)。
    *   *Save*: 点击保存 -> Loading Spinner -> 后端验证 -> Success Toast (或 Error Alert 显示具体行号)。
*   **Auth Files (文件管理)**:
    *   *Delete*: 点击删除 -> **AlertDialog (红色警告: \"此操作不可逆\")** -> 确认 -> Loading -> 列表刷新 -> Toast \"已删除\"。
    *   *Upload*: 拖拽/选择文件 -> 校验 JSON 格式 -> 进度条 -> 列表乐观更新 (Optimistic UI)。
*   **Settings (表单修改)**:
    *   *Toggle*: 点击开关 -> 立即变色 (乐观) + 后台请求 -> 若失败则回滚并 Toast 报错。

### 3. 组件拆分与复用建议 (Component Strategy)
*   **`PageHeader`**: 统一封装面包屑 (Breadcrumb)、页面标题 (`h1`)、右侧操作区 (Actions)。
*   **`StatusCard`**: 接收 `icon`, `label`, `value`, `status` (success/warning/error) 的展示卡片。
*   **`EmptyState`**: 统一空态。Props: `icon`, `title`, `description`, `actionButton` (ReactNode)。
*   **`ConfirmDialog`**: 封装 `shadcn/alert-dialog`。Props: `title`, `content`, `onConfirm` (Promise), `variant` (destructive/default)。
*   **`CopyButton`**: 封装 Icon Button，点击复制文本 + Tooltip 反馈 \"Copied!\"。

### 4. 视觉规范建议 (Visual Specs)
*   **容器**: 延续 `max-w-7xl mx-auto px-4 py-6`。
*   **卡片风格**: `bg-card/30 backdrop-blur border border-border` (玻璃拟态)。
*   **排版**: 标题使用 `font-semibold tracking-tight`。正文 `text-muted-foreground`。
*   **强调色**:
    *   Success: `text-green-500` / `border-green-500/20`
    *   Error: `text-destructive` / `border-destructive/20`
    *   Primary: `text-primary` (Cyan/Blue based on theme)
*   **图标**: 使用 `lucide-react` (Next.js 标准) 替换 FontAwesome，保持线框风格一致性。

### 5. 验收点 (Acceptance Criteria)
1.  **Dashboard**: 必须正确显示当前连接的 API Base URL 和连接状态 (Ping)。
2.  **i18n**: 所有静态文案包裹在 `t('key')` 中，切换语言无闪烁。
3.  **Theme**: 切换 Day/Night 模式时，Config 编辑器和图表颜色需同步适配。
4.  **Config**: 编辑器必须支持 YAML 语法高亮；保存失败必须阻断并提示错误。
5.  **Auth Files**: 删除操作必须弹出二次确认框；上传非 JSON 文件需拦截。
6.  **Responsive**: 侧边栏在移动端可收起 (Sheet)，内容区无横向滚动条。
7.  **Feedback**: 所有异步操作 (保存/删除/刷新) 均有 Loading 状态和 Toast 结果。
