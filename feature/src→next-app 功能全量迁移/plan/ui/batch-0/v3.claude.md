## 交互主路径

### `/settings` — 基础设置
- 进入 → 加载配置 → 展示开关/输入项卡片
- 修改 → 字段标记 dirty → 底部 Save 按钮激活
- 保存 → loading → 成功 toast / 失败 toast + 回滚值

### `/settings/providers` — Providers & OAuth
- 列表展示已配置 provider（卡片式）
- 添加/编辑 → 抽屉或模态 → 密钥输入（type=password，不回显）
- OAuth 跳转 → 回调写入 → 刷新列表
- 删除 → confirm（"不可逆"）→ 成功移除

### `/auth-files` — 认证文件管理
- 列表 + 搜索/筛选/分页 → 统计栏（总数/筛选数）
- 下载 → 直接触发 `/api/auth-files/download`
- 删除 → confirm（"不可逆，无法恢复"）→ 成功刷新

### `/config` — Config Editor
- 加载 → Monaco/CodeMirror 编辑器（只读模式可切换）
- 编辑 → dirty 标记 → Save/Discard 按钮组
- 保存 → 校验 → 成功 toast / 失败回滚 + 错误定位
- 重载 → confirm（"覆盖本地修改"）→ 拉取最新
- 下载 → 导出当前配置

### `/system` — 系统诊断
- 展示版本/连接状态/环境变量检测（缺失高亮）
- 复制按钮（版本/诊断信息）
- 排障提示卡片（env 缺失 → 建议操作）

### `/login` — 健康检查（无账号）
- 进入 → 自动检测后端连接
- 成功 → 绿色状态 + 跳转 Dashboard 按钮
- 失败 → 红色状态 + 错误摘要 + 重试

## 状态与边界

| 状态 | 处理方式 |
|------|----------|
| **loading** | 骨架屏/Spinner，禁用操作按钮 |
| **empty** | icon + 说明 + 主按钮引导 |
| **error** | 错误摘要 + 可复制 + Retry 按钮 |
| **disabled** | 按钮灰显 + tooltip 说明原因 |
| **confirm** | 模态/AlertDialog，文案含"不可逆" |
| **dirty** | 底部 Save 激活，离开页面拦截 |

### 需要回滚的操作
- Settings/Providers 保存失败 → 回滚表单值
- Config Editor 保存失败 → 保留编辑内容 + 错误提示
- 不可逆操作（删除/清空）无回滚，故需二次确认

## 组件职责边界

### 下沉到可复用组件（`components/`）
- `PageHeader` — 标题/副标题/操作区
- `StatusCard` — 连接状态/版本/健康度
- `EmptyState` — icon + 文案 + CTA
- `ErrorState` — 错误摘要 + Retry
- `ConfirmDialog` — 二次确认（支持"不可逆"文案）
- `DirtyGuard` — 离开拦截 + 提示
- `ListToolbar` — 搜索/筛选/刷新/批量操作
- `Pagination` — 分页控件

### 留在页面层
- 页面特有业务逻辑（如 Config Editor 校验）
- 页面级 state 编排（dirty/loading/error）
- 路由参数解析与 API 调用

### 文件行数控制
- 单文件 > 400 行 → 拆分 hooks/子组件
- 页面层 < 300 行为宜

## i18n / 主题

### i18n
- 所有文案通过 `useI18n().t("key")` 获取
- 新增页面必须同步补齐翻译字典（以本仓库现有 i18n 结构为准）
- 禁止硬编码字符串（包括 placeholder/tooltip）

### 主题
- 沿用 `ThemeProvider`（day/night/system）
- 新组件必须使用语义变量（`text-foreground`/`bg-card`）
- 验收时切换主题检查对比度

## 反模式/坑点清单

1. **密钥泄漏** — Provider key 只存服务端 env，API 响应不返回明文，前端输入 type=password
2. **日志大列表性能** — 沿用 `MAX_DISPLAY_LOG_LINES=2000` 限制 + 虚拟滚动备选
3. **不可逆操作提示不足** — 删除/清空必须 ConfirmDialog + "不可逆"文案
4. **dirty 状态丢失** — 页面跳转/刷新前拦截（`beforeunload` + `DirtyGuard`）
5. **Config 保存覆盖** — 保存前校验 JSON/YAML 格式，失败不提交
6. **空态无引导** — 每个列表页必须有 EmptyState + 主按钮
7. **错误不可复制** — ErrorState 需提供复制按钮
8. **主题硬编码** — 禁止 `text-white`/`bg-black`，用语义变量
9. **i18n 遗漏** — 新增文案必须双语同步
10. **OAuth 回调丢失** — 回调后刷新列表 + toast 反馈

---

## 验收点（≤10 条）

1. 所有新页面 day/night 主题下对比度达标
2. 所有文案无硬编码，中英切换正常
3. 删除/清空操作有二次确认 + "不可逆"文案
4. 表单保存失败时 UI 值回滚 + 错误 toast
5. 列表页空态有 icon + 引导按钮
6. 错误状态可复制 + Retry 按钮
7. Config Editor dirty 状态离开拦截
8. Provider 密钥不回显、不落库、不暴露客户端
9. 日志列表 ≤2000 行渲染，无明显卡顿
10. 单文件 < 600 行
