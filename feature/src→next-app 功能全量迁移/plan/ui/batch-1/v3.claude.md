# v3（专家B：Claude Opus 4.5）要点摘要 — OAuth 登录中心 / Batch 1

## 1) 主路径与边界（专家强调）
- 轮询停止条件：`ok` / `error` / 超时（5 分钟）/ 手动取消
- 错误后 3 秒 reset：展示错误摘要后自动回到可重新开始（同时提供立即重试/重置）
- 切换 Provider 丢状态：若正在轮询或已生成 URL，应弹 confirm（“切换将取消当前流程”）
- 页面卸载清理：组件 unmount 时必须 stop polling（避免内存泄漏与幽灵请求）

## 2) 状态机建议（利于实现阶段复用）
- `idle → generating → polling → success`
- `polling → error → (3s) → idle`
- `polling → timeout → idle`

## 3) 安全与敏感信息提示（必须落地）
- 浏览器只请求 Next `/api/*`，不直连 management API（密钥仅 server-side）。
- 授权 URL 含 `state`，等价一次性令牌：UI 需要醒目提示“请勿分享”。
- Cookie 可能含会话信息：高级区提示“仅限本人使用，提交后立即清空”。
- 不持久化敏感数据：`state/cookie` 不写 localStorage，页面离开即清空。

## 4) i18n 文案 key 建议（实现阶段落地）
- `oauth.title` / `oauth.generate` / `oauth.waiting` / `oauth.timeout` / `oauth.success`
- `oauth.securityTip` / `oauth.switchConfirm` / `oauth.cookieTip`

## 5) 验收点（<= 10）
1) 成功/失败/超时都能正确停止轮询
2) 切换 provider/重置会提示并能取消操作
3) 错误后 3 秒自动 reset
4) 复制 URL 有提示“已复制，请勿分享”
5) iFlow 才可见 Cookie 登录折叠区
6) 页面离开后无继续轮询请求
7) URL/cookie 不被持久化
8) 成功后 CTA 能跳转到 `/auth-files`
9) 文案可 i18n（en/zh 都补齐）
10) 暗色主题下状态色与对比度可读
